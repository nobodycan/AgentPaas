# Agent PaaS 领导演示讲稿（5 分钟）

## 演示前准备

- 使用 1366×768 或 1440×900、浏览器缩放 100%，从 `/overview` 开始。
- 在左侧「演示导览」底部点击「重置演示」，确认右上角显示「演示数据」。
- 全程沿用预填的「智能采购助手」配置，避免现场输入；所有等待动画都可跳过。

## 现场重置与兜底

1. 点击左侧「演示导览」底部的「重置演示」，会清除本地演示状态并返回 `/overview`。
2. 若动画还在进行，先点「重置演示」再刷新页面；不要连续重复提交创建、回滚或隔离操作。
3. 若时间不足，按左侧主导航直接跳到「安全事件」和「审计中心」，保留风险控制与证据闭环两段。
4. 若窄屏隐藏了演示导览，使用主导航或本表中的直达路径；表格可在卡片内部横向滚动。
