# Agent PaaS 文档索引

本目录按“事实调研、产品论证、正式设计”分层，避免把竞品事实、产品假设和技术结论混在一起。

## research

- `agent-hosting-competitor-research.md`：主流 Agent 托管平台的公开产品能力、操作旅程与来源。

## product

- `agent-paas-investment-brief.md`：面向产品经理、BA 和项目决策者的立项论证材料。
- `agent-paas-user-journey.md`：目标用户、业务旅程、配置清单和页面信息架构。
- `agent-paas-governance-scope.md`：审计、入站/出站流量控制与 AI 安全护栏的产品责任、边界和分期。
- `agent-paas-security-threat-model.md`：单 Agent 失陷、横向移动、模型凭证泄露与安全沙箱联动的首要事故模型。
