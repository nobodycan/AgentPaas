# Agent PaaS 领导演示前端设计

> 日期：2026-07-29
>
> 状态：已确认交互方向，待书面审核
>
> 目标：用 5 分钟现场点击演示 Agent 从 OCI 镜像到受控生产服务的完整旅程

## 1. 设计结论

交付物不是静态汇报页，而是一套可运行、可导航、状态会变化的多视图 React 前端原型。所有业务数据与异步过程均由前端 Mock，不依赖后端、真实 Kubernetes、负载均衡、模型网关或安全沙箱。

产品外观采用企业平台控制台形态，并增加“下一步演示”引导。演示者既可以沿预设剧本在 5 分钟内完成主旅程，也可以自由点击导航、详情页签、筛选器、抽屉和操作按钮。

核心记忆点：

1. 一个 OCI 镜像经过少量业务化配置，快速获得可访问、可运维、可约束、可审计的 HTTPS Endpoint。
2. 单个 Agent 疑似被攻破时，平台可以独立摘流、断网、吊销身份、替换实例并还原证据链，从而限制爆炸半径。

## 2. 目标与非目标

### 2.1 目标

- 向领导直观说明 Agent PaaS 的业务价值与投资必要性。
- 真实模拟创建环境、异步部署、SSE 调用、会话亲和、Revision 回滚和安全事件处置。
- 展示 Environment、Revision、Instance、Endpoint 等核心产品对象及其关系。
- 展示 Ingress、Egress、安全基线、模型身份、短期安全任务和审计能力。
- 明确平台是 Agent 生产运行与治理底座，不是 Kubernetes 控制台或 Agent 编排器。
- 通过“重置演示数据”保证每次演示都能从相同状态开始。

### 2.2 非目标

- 不连接真实集群、LB、域名、证书、模型、日志或安全系统。
- 不实现登录、权限校验、后端持久化和多人协作。
- 不实现真实 Session 资源或 Session 管理页面。
- 不把企业短期安全沙箱展示为长期 Agent Runtime。
- 不实现真实计费、自动伸缩、灰度发布、MCP 托管或提示词检测引擎。
- 不宣称 Mock 指标是真实收益数据。

## 3. 目标受众与演示语境

主要受众是 AI 平台负责人、研发效能负责人、基础设施负责人、产品经理和 BA。页面默认以产品与业务语言表达，不要求观众理解 Deployment、ReplicaSet、Service、Ingress 或 Pod Template。

演示使用桌面或会议室大屏，默认中文界面。核心信息在 1440×900 左右的首屏内清晰可见，并兼容常见 13–16 英寸笔记本。

## 4. 5 分钟演示剧本

### 4.1 价值驾驶舱，约 30 秒

从“概览”开始，展示：

- 运行环境、就绪实例和近期发布数量；
- 发布成功率、策略生效率和审计覆盖率；
- 容量、路由和安全告警；
- “镜像到 Endpoint：3 天 → 18 分钟”“人工步骤：23 → 5”等演示收益。

所有收益指标旁固定显示“演示数据 · 待试点验证”。

### 4.2 部署新 Agent，约 60 秒

点击“部署新 Agent”，进入四步创建向导：

1. 基本信息：租户、项目、名称、描述和负责人；
2. 镜像与运行：OCI 镜像、版本、端口、RuntimePlan 和副本；
3. 配置与治理：环境变量、Secret 引用、Ingress Profile、Egress Profile、安全基线和可选 SecureTaskProfile；
4. 访问与确认：Endpoint 可见性、会话 Header、平台域名和配置摘要。

演示预置完整数据，不要求现场逐字输入。页面强调无需填写 Kubernetes YAML、证书私钥或模型厂商 API Key。

### 4.3 从镜像到生产 Endpoint，约 40 秒

提交后立即创建环境并进入异步部署页。模拟时间线依次完成：

1. 配置已接受；
2. 镜像 Tag 已解析并固化 Digest；
3. 工作负载身份与 Ingress/Egress 策略已生效；
4. 必需的 SecureTaskProfile 已校验；
5. 实例已启动；
6. 健康检查通过；
7. LB 后端注册完成；
8. HTTPS Endpoint Ready。

进度在数秒内可视化推进。只有实例、网络策略、安全基线和 Endpoint 均已就绪，环境才显示 Running。

### 4.4 SSE 与会话亲和，约 40 秒

从环境详情进入“访问与测试”：

- 默认填入 `X-Agent-Session-ID: demo-user-1024`；
- 点击发送后逐字模拟 SSE 流式响应；
- 展示 Request ID、Revision 和命中的实例；
- 再次发送相同会话键，命中同一实例；
- 更换会话键后允许命中另一实例；
- 页面明确说明这是尽力亲和，实例变化后允许重新映射。

页面不创建 Session 对象，不提供 Session 列表。

### 4.5 Revision 与回滚，约 40 秒

进入“Revision / 发布记录”，展示当前稳定版本和一个健康检查失败的新版本。用户可以：

- 查看镜像 Digest、RuntimePlan、变量和副本差异；
- 查看新实例启动、健康检查和 LB 注册阶段；
- 展开失败原因；
- 点击“回滚到稳定版本”；
- 观察期望 Revision 切回、旧版本重新就绪和流量恢复。

### 4.6 安全事件处置，约 65 秒

进入“安全与治理”或“安全事件”，打开“未授权出站尝试”事件：

- 风险主体关联到租户、项目、Environment、Revision、Instance 和工作负载身份；
- 页面显示 Egress Profile 已拒绝未知公网地址；
- 模型供应商长期 API Key 未进入 Agent，模型调用由网关身份代持；
- 高危 Shell、浏览器、代码和文件任务仅能委托给短期安全沙箱；
- 点击“一键隔离”后依次模拟 LB 摘流、阻断出站、吊销工作负载身份、吊销模型身份、停止异常实例和不可变替换；
- 每一步生成时间、结果、Operation ID、Request ID 或 Task ID，并进入审计时间线。

安全承诺文案为：单个 Agent 完全失陷时，损失被限制在该 Agent 已明确获得的短期、有限、可审计和可吊销能力内。

### 4.7 投资结论，约 25 秒

点击“查看投资价值”回到总结视图：

- MVP：Hosting 闭环、会话亲和、发布运维、网络约束和基础审计；
- 第一阶段增强：弹性伸缩、灰度发布、Guardrail、Tool/MCP 策略；
- 长期：统一资源池调度、策略治理与企业 Agent 运行底座。

## 6. 页面与交互设计

### 6.1 全局框架

- 左侧导航用于自由探索；
- 顶部展示当前租户、项目、演示数据标识和全局搜索；
- “演示模式”浮动控制条展示当前步骤、下一步动作、剩余步骤和重置入口；
- Toast 用于复制成功、模拟操作完成和非阻塞错误；
- Drawer 用于实例、Revision、审计和安全事件详情；
- Modal 仅用于高风险确认与回滚确认。

### 6.2 概览

概览不是通用 BI 大屏，而是回答：

1. 平台现在是否健康；
2. Agent 交付效率是否改善；
3. 哪些运行环境需要关注；
4. 网络、安全和审计策略是否真实生效；
5. 下一步应该执行什么动作。

关键卡片都可点击进入对应筛选后的列表。

### 6.3 运行环境列表

支持：

- 按综合状态、项目、负责人和 RuntimePlan 筛选；
- 搜索环境名称和 Endpoint；
- 点击环境进入详情；
- 快捷执行测试、更新、停止或查看安全状态；
- 显示当前 Revision、就绪/期望实例、Endpoint、集群和最近更新时间。

### 6.4 创建向导

- 使用清晰的四步 Stepper；
- 每一步进行前端校验并保留输入；
- 普通字段与高级配置分层；
- Secret 仅展示引用，不展示明文；
- 安全基线在生产环境强制开启且不可关闭；
- SecureTaskProfile 旁说明“仅保护委托的短期任务，最长数小时”；
- 最终确认页展示业务化摘要，不展示原始 Kubernetes YAML。

### 6.5 环境详情

首屏必须立即回答：

- 当前是否可用；
- 应调用哪个 URL；
- 当前运行哪个 Revision；
- 有多少实例就绪；
- 最近发布是否成功；
- Ingress、Egress 和安全基线是否生效；
- 发生异常时应进入哪个页面。

### 6.6 审计中心

审计中心提供四种清晰分离的视图：

- 操作审计；
- 访问审计；
- 安全事件；
- 应用运行日志。

支持按时间、身份、Environment、Revision、Instance、结果和关联 ID 筛选。Prompt、响应正文和模型思维链默认不进入通用审计。

### 6.7 资源池与 Profile 管理

资源池页展示租户专属集群、健康、容量、环境数、实例数和放置风险。Profile 管理展示 Ingress、Egress、SecureTask、身份、日志、域名/证书等平台预置策略。

这些页面可浏览、筛选和查看详情，但本次演示不实现复杂编辑器。

## 7. Mock 数据与状态变化

### 7.1 初始数据

初始数据至少包含：

- 8–12 个不同状态的运行环境；
- 20–30 个运行实例；
- 3 个租户专属集群；
- 4 种 RuntimePlan；
- 多个 Ingress、Egress、SecureTask 和身份 Profile；
- 稳定、部署中、失败和已回滚的 Revision；
- 正常访问、策略拒绝、发布失败和安全隔离等审计记录；
- 一个可触发处置的高风险安全事件。

### 7.2 前端状态

Mock 状态由浏览器内存管理，并可选择保存在浏览器本地存储中，以支持页面跳转和刷新。点击“重置演示数据”后恢复到确定的初始数据集。

以下操作必须真实改变页面状态：

- 创建环境；
- 部署阶段推进；
- 生成 Endpoint；
- SSE 响应与实例命中；
- Revision 回滚；
- 实例摘流与替换；
- 安全事件隔离；
- 新增审计记录；
- 列表筛选与搜索。

所有异步过程使用确定性的短延时，不依赖随机成功或失败，确保现场演示可复现。

## 8. 前端架构

前端放在仓库独立的演示应用目录中，使用 React 与 TypeScript，保持无后端运行能力，并兼容静态或托管发布。

主要模块：

| 模块 | 职责 |
|---|---|
| 应用框架 | 导航、路由、租户上下文、演示模式控制条 |
| Mock 数据仓库 | 提供 Environment、Revision、Instance、Endpoint、Profile、AuditEvent 等数据 |
| 演示场景引擎 | 管理演示步骤、确定性异步进度、下一步跳转和重置 |
| 运行环境模块 | 列表、创建向导、详情与配置摘要 |
| 发布模块 | Revision 差异、部署时间线、失败原因和回滚 |
| 访问测试模块 | SSE 模拟、会话亲和、Request ID 与实例命中 |
| 治理模块 | Ingress/Egress、安全基线、模型身份和 SecureTaskProfile |
| 安全事件模块 | 风险详情、隔离操作和证据时间线 |
| 审计模块 | 操作、访问、安全和运行日志查询 |
| 资源模块 | RuntimePlan、集群容量和 Profile 浏览 |

页面组件只通过 Mock 数据仓库和场景引擎读写演示状态，避免把业务状态散落在各页面内部。

## 9. 视觉方向

采用克制、可信的企业控制台风格：

- 深海军蓝侧栏，浅灰白内容背景；
- 青绿色表示可用与受控，蓝色表示信息，琥珀色表示风险，红色只用于失败和高危动作；
- 使用紧凑但有呼吸感的卡片、表格、状态徽标和时间线；
- 避免大面积渐变、玻璃拟态、营销插画和夸张动画；
- 首屏突出业务状态与下一步行动，而不是堆叠图表；
- 部署、SSE 和隔离过程使用轻量动画帮助观众理解状态变化；
- 所有演示指标和 Mock 数据均有稳定、可见的标识。

## 10. 异常与边界处理

- 创建向导必填项缺失时在当前步骤提示，不丢失已填内容；
- 部署失败时显示失败阶段、原因、建议动作和日志入口；
- SSE 模拟可取消，取消后保留已产生的 Request ID；
- 回滚和隔离操作需要明确确认，但演示模式可以提供预填确认；
- 重复点击异步操作不会创建重复事件；
- 安全隔离开始后，相关 Endpoint 立即显示 Draining，并在完成后显示 Isolated；
- 页面刷新不会把处置中的对象误显示为健康；
- 空列表、无搜索结果和加载状态均提供清晰说明。

## 11. 可用性与无障碍

- 所有主要操作可通过键盘访问；
- 焦点状态清晰；
- 状态不只依赖颜色表达；
- 表单字段有明确标签、错误说明和帮助文本；
- Drawer、Modal 和 Toast 具备正确的可访问语义；
- 页面在常见桌面尺寸下无横向溢出；
- 小尺寸屏幕可以折叠侧栏，但不以手机演示为主要目标。

## 12. 验收标准

### 12.1 功能验收

- 至少六个一级导航入口可以点击并展示独立内容；
- 环境详情至少七个页签可以切换；
- 创建向导可以完成并创建新的 Mock 环境；
- 部署进度可以从草稿推进到 Endpoint Ready；
- 两次相同会话 Header 的请求命中同一实例；
- SSE 响应具有可见的流式输出过程；
- 失败 Revision 可以查看差异并完成回滚；
- 安全事件可以执行一键隔离并生成完整时间线；
- 审计中心能通过关联 ID 找到对应记录；
- 重置操作可以恢复全部演示初始状态。

### 12.2 内容验收

- 不出现 Session 一级对象或 Session CRUD；
- 不把 SecureTaskProfile 描述为长期运行时；
- 不宣称安全沙箱能保护已交给 Agent 的凭证；
- 明确供应商长期模型 Key 由模型网关代持，不进入 Agent；
- 所有收益与运营指标标注为演示数据；
- 普通用户界面优先使用 Agent 产品语言，而非 Kubernetes 资源语言。

### 12.3 质量验收

- 生产构建成功；
- 所有核心路由可直接访问和刷新；
- 浏览器控制台无阻塞性错误；
- 完整演示旅程可在 5 分钟内完成；
- 演示重置后可以立即重复执行；
- 不向外部服务发送业务请求，不包含真实凭证和内部敏感数据。

## 13. 交付物

- 可运行的 React/TypeScript 演示前端；
- 完整 Mock 数据和可复现演示场景；
- 本地运行方式；
- 可供领导直接访问的托管演示地址；
- 简短的 5 分钟演示讲稿；
- 必要的构建与交互验证记录。
